# 0.1.6 — 2026-08-23

## Added

- **Community health files** — contribution and conduct guidance now route bug reports, framework issues, and private vulnerability reports to the right channels.

## Changed

- **MCP SDK v2 protocol surface** — HTTP supports the sessionless 2026-07-28 request path alongside 2025 clients, tool schemas reject undeclared root input keys, advertised output schemas include the structured error envelope, and emitted JSON Schema uses 2020-12.
- **Session mode** — `.env.example`, the container, and the README now set `MCP_SESSION_MODE=stateless` explicitly; `auto` remains documented as the schema default that resolves to stateful.
- **Request context** — the NPS service passes the handler `Context` directly through `fetchWithTimeout` and `withRetry`, preserving request correlation and cancellation under the closed SDK v2 context type.
- **TypeScript 7 gate** — the typecheck config now includes `tests/` while the build config emits only `src/`; test contexts are typed against each tool's error contract and strict indexed access is explicit.
- **Container and packaging baseline** — Bun 1.4 images, build-platform pinning, optional-peer omission, native-binding bundle pruning, anchored generated-data ignores, and current framework verification scripts are adopted.
- **Framework skills and agent docs** — downstream workflow/reference skills and the server protocol guides are synchronized to `@cyanheads/mcp-ts-core` 0.12.3.

## Dependencies

- **`@cyanheads/mcp-ts-core`** `^0.10.14` → `^0.12.3`.
- **`typescript`** `^6.0.3` → `^7.0.2`.
- **Dev tooling** — `@biomejs/biome` `2.5.2` → `2.5.9`, `@types/node` `26.1.1` → `26.2.0`, `tsc-alias` `^1.9.1` → `^1.9.2`, and `vitest` `^4.1.10` → `^4.1.11`.
