# 0.3.2 — 2026-11-20

## Added

- **Activities and event requirements.** Activity results include pet restrictions and reservation or permit instructions. Event results include registration status and instructions, including when no registration link is published. ([#33](https://github.com/cyanheads/national-parks-mcp-server/issues/33))
- **Campground details.** Campground results include operating schedules and dated exceptions, electrical hookup and site-type counts, and RV and trailer length limits. ([#35](https://github.com/cyanheads/national-parks-mcp-server/issues/35))

## Fixed

- **Event dates.** Scheduled dates exclude published cancellations. Cancelled dates use the same query window, and the text distinguishes the record’s original dates from scheduled dates. ([#31](https://github.com/cyanheads/national-parks-mcp-server/issues/31))
- **Fee categories.** Park and campground searches show the first listed fee with its category and distinguish a zero amount from an unpublished amount. ([#32](https://github.com/cyanheads/national-parks-mcp-server/issues/32))
- **Park hours.** Park details include dated exceptions with the published labels, dates, and weekday hours when available. ([#34](https://github.com/cyanheads/national-parks-mcp-server/issues/34))
- **Activity attribution.** Shared activities use the requested park code when it appears among their related parks. ([#36](https://github.com/cyanheads/national-parks-mcp-server/issues/36))
