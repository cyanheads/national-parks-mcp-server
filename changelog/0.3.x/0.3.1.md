# 0.3.1 — 2026-11-14

## Changed

- **Error envelopes** no longer carry the upstream NPS error body in `structuredContent.error.data` (mcp-ts-core 0.13.22).
- **`initialize`** advertises the server description in `serverInfo`, read from `package.json` (mcp-ts-core 0.13.21).
- **Bun engines floor** rises from 1.4.0 to 1.4.4 in `package.json`, agent docs, and the README.
- **`.env.example`** documents `MCP_JWT_EXPECTED_AUDIENCE` and `MCP_JWT_EXPECTED_ISSUER`.
- **Development tooling** syncs framework skills and scripts with mcp-ts-core 0.13.22: `devcheck` and `release:github` parse arguments strictly, and the MCPB bundle cleaner strips `AGENTS.md`/`CLAUDE.md` at every dependency's package root, not only mcp-ts-core's.

## Fixed

- **`nps_get_park` unresolved codes** now render as `**Unresolved codes:** zzzz` in `content[]`; the label was dropped when `render` was set ([#28](https://github.com/cyanheads/national-parks-mcp-server/issues/28)).
- **`nps_find_campgrounds` site counts** render an unknown reservable or first-come count as `unknown` rather than `0`; a published `0` still reads `0` ([#25](https://github.com/cyanheads/national-parks-mcp-server/issues/25)).
