# 0.3.0 — 2026-10-28

## Added

- Serve national-parks-guide as the `skill://national-parks-guide/SKILL.md` MCP resource.
- **Visit-planning guidance** checks park identity, access, campground reservation evidence, and recurring-event dates; it ships with npm, plugins, MCPB, and Docker.
- **Agent Plugins** root `plugin.json` and `mcp.json` provide the standard plugin entry points alongside the client overlays.

## Changed

- **Framework responses** adopt mcp-ts-core 0.13.17 HTTP request cleanup and 0.13.18 literal enrichment text rendering, including trailing-hash escaping.
- **Setup documentation** leads with hosted and local connection commands and consolidates Docker and source instructions.
- **Development tooling** syncs framework guidance and packaging checks; the dependency minimum release age is one day.

## Fixed

- **MCPB packaging** preserves nested SDK skill runtime modules while removing package-root agent documentation, node-gyp build output, and build-only files.
- **Campground guidance** directs hookup and date-specific availability checks to linked campground pages.
