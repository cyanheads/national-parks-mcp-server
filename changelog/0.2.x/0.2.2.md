# 0.2.2 — 2026-10-25

## Changed

- **Server instructions** identify NPS text as source data rather than instructions.
- **Hosted setup** documents Claude Code, Cline, Cursor, and Claude Desktop configuration.
- **Development tooling** syncs framework skills, attributes shared audit advisories to the installed direct dependency, and requires a separate release review.

## Fixed

- **All six tool formatters** preserve literal NPS text and caller notices through CommonMark parsing, including multiline titles, while rendering link and image fields with their original destinations ([#24](https://github.com/cyanheads/national-parks-mcp-server/issues/24)).
- **Framework responses** adopt mcp-ts-core 0.13.16, which escapes error and enrichment text in Markdown responses and identifies invalid startup timer/count settings.
